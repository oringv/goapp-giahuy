## Video 7
Chào Mừng Đến với Gin Framework! Xây dựng API GET Đầu Tiên Cực Nhanh

Gin ?
Gin Framework là một web framework nhẹ và nhanh trong Go (Golang), dùng để xây dựng RESTful API và ứng dụng web. Gin dựa trên net/http, cung cấp cú pháp đơn giản, hiệu năng cao, và các tính năg như:
Routing: Dễ dàng định nghĩa endpoint (ví dụ: GET/ users)
Middleware: Hỗ trợ xử lý xác thực, logging, CORS...
JSON handling: Tự động mã hóa/ gửi JSON (như c.JSON)
Hiệu năng: Tối ưu tốc độ, phù hợp cho API quy mô lớn.

## Video 8
URL, Path, Path Param và Query Param - Làm chủ Các Thành Phần của Endpoint

URL (Uniform Resource Locator) là địa chỉ của một tài nguyên trên web, giống như địa chỉ nhà giúp bạn tìm đúng nơi cần đến.
Trong API, URL được dùng để xác định hành động (như lấy dữ liệu, tạo mới, sửa, xóa...) và tài nguyên (thành viên, sản phẩm).

Các thành phần chính của URL, xác định tài nguyên hoặc hành động mà API xử lý. Nó thường là đường dẫn sau domain.
