## Video 2
Phân loại API và Tìm Hiểu Chuyên Sâu Về RESTful API Là Gì?

RESTFUL?
RESTful API(REST API) là một cách để các ứng dụng giao tiếp với nhau 

Get lấy dữ liệu từ server(không làm thay đổi dữ liệu)
Post Gửi dữ liệu lên server để tạo mới tài nguyên
Put Cập nhật toàn bộ tài nguyên (nếu không có thì tạo mới)
Patch cập nhật một phần tài nguyên 
Delete Xóa tài nguyên
Head Giống GET nhưng chỉ trả về header, không có nội dung (body). Dùng để kiểm tra tài nguyên có tồn tại không
Options Hỏi server xem tài nguyên hỗ trợ những phương thức HTTP nào(dùng để kiểm tra khả năng giao tiếp )

Giao thức HTTP?
Giao thức HTTP (viết tắt của HyperText Transfer Protocol) là giao thức truyển tải dữ liệu trên web - nó giống như ngôn ngữ giao tiếp giữa trình duyệt (client) và máy chủ (server)

JSON Là Gì? Tất Tần Tật Về Định Dạng Dữ Liệu Phổ Biến Nhất Của API!

JSON (JavaScript Object Notation) là một định dạng dữ liệu nhẹ, dễ đọc, được sử dụng để trao đổi thông tin giữa các chương trình. JSON sử dụng key-value và có cấu trúc như đối tượng (object) hoặc mảng (array)
